# Code of Conduct

GSD Master is a public development-skill project. Contributors, reviewers and
maintainers are expected to keep discussions respectful, specific and focused
on improving the skill and its evidence-based development workflow.

Unacceptable behaviour includes harassment, discrimination, doxxing, threats,
deliberate credential or private-data disclosure, and intentionally bypassing
documented safety or review controls.

Report conduct concerns privately to the project maintainer listed in the
repository's current GitHub contact information. Do not include secrets or
private source material in a report.
